# PlainKit · 工具候选池 v2

> 后续工具的候选调查、裁决记录与**可直接照做的排期队列**。
> 本文档是候选池的唯一事实来源。每个候选排期开工前必须重新过竞品扫描（本档案 §6 的记录有效期 30 天）。
> 基线扫描日期：2026-09-25（GitHub 仓库数据当日经 API 核实：星数 / 最近推送 / 协议）。
> 上一版（2026-09-24）的裁决被本次推翻的部分在 §7 有记录，不要按旧结论执行。
>
> **一个不变的背景发现**：2024–2026 年的 AI 工具站浪潮已把几乎所有「经典工具」
> 做成了「本地计算 + 免费 + 无水印 + 无注册」。**不要再押注「我们更干净」作为差异点**——
> 竞品已经干净了。差异化只剩三条路：①产物即内容（ASCII、二维码、图表卡、成就卡）②工具集的
> 统一入口与可信品牌（PlainKit 的根本策略）③工具间协同。选品时按这个顺序想。

## 0. 排期总规则（先读这个，再谈做哪个）

1. **Gate 0 —— 发布优先于一切新工具**。首发帖（见 `docs/发布/首次发布_2026-09-24.md`）发出去之前，不开工队列里的任何一项。理由：候选池里没有任何工具比「让已有 6 个工具被人看见」更值钱；先建后发只会让验证窗口空转。
2. **每个工具完成 = 一次公告事件**（产品概述 §7 的滚动发布）。做完不发，下一个不开工。
3. **成本红线**：工具页 JS 预算 ≤10KB gzip（DESIGN.md）。任何依赖压缩后预估超预算的，直接否决，不进队列（PDF 被否就是这条，见 §4）。
4. **可分享产物门槛不豁免**：过不了「结果值得发出去」的工具一律进 §3 留存补丁包，不进队列——哪怕它很有用。
5. **排期前重扫**：距离上次扫描超过 30 天的候选，先补 3 组关键词扫描再开工。
6. **每个队列项都有证伪条件**。触发即停，不加救场功能。

**排序原则（按权重）**：①渠道可得性（我们实际够得着的分发渠道）②产物即内容 ③实现成本 ④验证信号（能否产生「有人第二次来/提反馈/转发」）⑤红线合规。留存型工具（压缩、清洗）在 ④ 上得分高但 ② 上为零，所以被规则 4 挡住——这是故意的：先证明传播假设，再做留存。

## 1. 排期队列（按顺序做，不要跳）

### #1 随机分队 · 游戏模式（random-picker v2）

- **做什么**：在现有 random-picker 上加「游戏模式」：按能力值平衡分队（`名字:评分` 语法）、每队指定队长、可选固定搭档约束，输出**队伍卡 PNG**（复用现有 canvas 卡）。
- **可分享产物**：队伍分配卡。竞品全在「复制文本」上止步——今日扫描的 4 家（recatools / kordu / skycally / pickteams）无一产出图片卡。平衡算法是贪心蛇形分配，量级很小。
- **竞品（3 组关键词，2026-09-25）**：`D&D party generator balanced`（freeonlinetools 等，低质量饱和）、`split friends into balanced teams gaming raid roster`（recatools 有技能平衡、kordu 主打 gaming、pickteams 有技能/性别标签+分享链接）、`random team generator skill`（同上）。
- **成本**：**低**。随机算法、名单输入、canvas 卡全部已在 random-picker 里，新写的只有平衡分配纯函数 + 一组表单。
- **为什么排第一**：全候选池唯一有现成分发渠道的——你在 Reddit 游戏板块是熟面孔（PROJECT-BRIEF §8），而游戏板块只排斥「外来者丢链接」，工具本身说得通就不算 off-topic。成本也最低，能最快兑现「每周上新」的承诺（首发帖里写了 weekly，得有收据）。
- **证伪条件**：游戏板块发帖被删/零互动，且换 2 个板块仍如此 → 「渠道资产」假设失效，此工具降级为普通更新，后续不再为它投入。

### #2 图表制作器

- **做什么**：粘贴数据（逗号/换行分隔）→ 柱状图 / 折线图 / 饼图三选一，canvas 渲染，导出 PNG 卡（带 PlainKit 标识）。**第一版封顶三种图**，不做图表库级别的东西。
- **可分享产物**：图表图片本身——贴进报告 / PPT / Discord。目标用户（学生、上班族）的真实高频需求。
- **竞品（2026-09-24 扫描，未过 30 天有效期）**：digitalheroesco（无库手绘 canvas）、instacharts、calculatorkits——饱和，但同样无「图片卡+品牌标识」形态，且普遍偏设计感（慢、花哨）；我们卖「贴上数据 3 秒出图」。
- **成本**：中。手绘 canvas 图表（柱/线/饼）+ 数据解析纯函数，无依赖（d3 解包 851KB，绝不引入）。
- **为什么排第二**：目标人群匹配度最高的产物型工具；比词云便宜，比打字测试差异化稍好。
- **证伪条件**：上线两周内图表图零外流（无人在别处贴我们的图表）→ 「报告配图会回流」假设失效。

### #3 打字速度测试（缩圈版）

- **做什么**：60 秒测试，WPM + 准确率 + **成就卡 PNG**。**只做这一种时长、一种界面、无排行榜、无主题系统、无历史记录。**
- **可分享产物**：WPM 成就卡。
- **竞品（2026-09-24 扫描 + 2026-09-25 API 核实）**：monkeytype（**20,761 星，最近推送 2026-09-23，极度活跃**）、typingtest.now（排行榜+反作弊）、typingtest.com。红海确认。
- **成本**：中。词表 + WPM/错误率纯函数不难，难的是逐字符高亮的输入状态机和移动端体验。
- **为什么还在队列里（以及为什么降级）**：原裁定是工具 8 首位，本次降级——**成就卡不是差异化**（monkeytype 的结果卡早已是社区通用货币），我们只剩「无账号 + 面向普通人 + 卡片带品牌」这一层。它排第三而不是被砍，是因为「练习-重测」循环是候选池里最强的**回访**机制，而回访正是验证判据之一。若做，严格按缩圈版执行，禁止膨胀成 monkeytype 平替。
- **证伪条件**：上线两周内成就卡零外流 → 停止投入，不再迭代。

## 3. 留存补丁包（被可分享产物门槛挡住，站内有自然流量后再做）

| 候选 | 定位 | 解锁条件 |
|---|---|---|
| 图片压缩 / 格式转换（HEIC→JPG、WebP） | 「文件不离开你的电脑」隐私牌；留存型 | 站内已出现自然回访（不是发帖带来的一次性流量） |
| 文本清洗台 | 上班族高频，用完即走 | 同上 |
| 百分比套件 | 同上 | 同上 |

> 2026-09-25 核实：Squoosh（Google 出品，**25,948 星，2026-09-23 仍在推送**，Apache-2.0）已把「浏览器本地压缩」做到极致——我们若做，唯一角度是给普通人的极简批量版，且它本来就排在留存包而不是队列里。

## 4. 明确不做（粗体为本次新增/更新）

- **PDF 工具（合并/拆分/压缩）——技术不可行性已核实**：pdf-lib 解包 19,005 KB、pdfjs-dist 33,966 KB，压缩后预估仍超工具页 10KB gzip 预算一个数量级。要做必须改 DESIGN.md 预算（用户决策），默认否决。加上无产物、竞品饱和，三重否决。
- **像素头像 / identicon 生成器——2026-09-25 扫描后出局**：DiceBear（9,710 星，MIT，2026-09-23 活跃）自带免费在线 playground + 全风格库 + PNG/SVG 导出；另有 minidenticons、PixelPeeps 等。DiceBear 已经免费提供了我们想做的一切，差异化趋近于零。
- 摩尔质量单独成工具、Pomodoro/计时器、密码生成器、掷骰子/转盘、梗图模板库、网速测试（原有结论不变）
- **AI 生成类**（不变）：核心功能全部确定性

## 5. 复活制

- **化学工具（编号 3）**：复活条件不变——用户班级渠道仍在且愿意分发（学年保质期）。触发则插队到 #2 之前（它是二期 AI 增强「解释这一步为什么」的最佳位置）。
- **词云生成**：从「观望」改挂**复活制**——复活条件：#2 图表或 #3 打字测试验证了「图片产物能带来外流」，且届时重扫。2026-09 扫描记录：wordcloud.app / digitalheroesco / gizmoop 已把本地渲染+PNG/SVG 做成标配；WordArt、微词云占据通用心智；成本中高（螺旋排版+碰撞检测；CJK 输入可用浏览器内置 Intl.Segmenter，无需分词依赖）。
- **单位换算**：等站点有权重再补，长期资产（Google 直接给答案，短期零流量）。
