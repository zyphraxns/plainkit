# PlainKit · 产品概述

> **这是本项目的产品定义，是唯一事实来源。** 所有下游环节（技术栈、项目结构、开发规范、每个工具的需求澄清）都以本文件为准。
>
> 本文件**只写结论，不写依据**。调研数据、被推翻的决策、发布与冷启动策略见仓库根目录的 `PROJECT-BRIEF.md`（那是决策档案，不是下游 skill 的输入）。
>
> 定稿时间：2026-09-21

---

## 1. 一句话描述

一套干净、免费、不用注册、全部在你浏览器里算完的日常小工具集合。

| 项 | 内容 |
|---|---|
| 名称 | **PlainKit** |
| 形态 | 纯静态网站（无后端、无数据库、无用户账号） |
| 界面语言 | **英文**（中文版是第二期的事，第一版不做多语言切换） |
| 托管 | Cloudflare Pages（主站）+ GitHub Pages（镜像），成本 0 |
| 域名 | `.app` 后缀（学生包走 Name.com 领）。**不用 `.me`** |
| 开源协议 | **Apache-2.0** |
| 预算 | 0 |

---

## 2. 目标用户

**不是开发者的普通人**——学生、上班族、偶尔需要算点东西的人。

他们有明确的共同处境：日常小工具散落在几百个满屏广告的小网站里，没有干净可信的入口。

> **一个必须知道的现实**：早期通过 Reddit 来的访客画像会偏向开发者，不是普通人。这不算失败（开发者会提有用反馈、会给 star），但**不能把它误读成「目标人群验证成功」**。

---

## 3. 目标与成功标准

| 时间 | 目标 |
|---|---|
| 3 个月 | 验证「有人愿意用」——判据是**有没有人第二次来、有没有人提反馈、有没有人把它发给别人**，不是用户数量 |
| 12 个月 | 300–500 个 GitHub 星 |

**首要目标是真实用户，不是星数。** 50 个真用户在用 > 500 个星但零反馈。

**一个必须现在就知道的矛盾**：普通人不会给你 star（他们不知道 GitHub 是什么）。会给星的是开发者。所以做法只有一个——**做成「普通人爱用、开发者愿意 star」的东西**：选品服务普通人，技术上做到纯静态、零依赖、秒开、可自托管、代码干净。

---

## 4. 差异化

**靠「更省事」赢，其次靠「好看」。**

- 零安装、零配置、打开就能用
- 一个入口，统一界面，不用在广告堆里找
- 干净的视觉——克制、统一、可信赖

**不是**靠功能数量（it-tools 已经 200+ 工具）也不是靠搜索排名（新域名 9–18 个月才有搜索流量）。

---

## 5. 四条底线（硬约束，不可协商）

1. **无广告**
2. **无追踪**
3. **无注册**（不用注册就能用，打开即用）
4. **所有计算在浏览器本地完成，数据不出设备**

配套的技术约束：

- 纯静态，无后端、无数据库、无用户账号
- 零第三方脚本
- 首屏要快、移动端可用、可自托管（`npm run build` 出静态文件即可部署）

> 这四条是对比「满屏广告的小工具网站」的杀伤性差异，也是本项目的核心卖点。首页显著位置必须写清「无广告、无追踪、不上传、开源、可自托管」——这句话同时打动普通人和开发者。

## 6. 核心板块（首批 5 个工具）

### 6.1 每个工具都必须满足的通用硬性要求

**这五条是对外承诺，也是验收的通用前提。**

1. **必须有一个「可分享产物」**——一张卡片、一张图、一个可复制的链接、或一个天然要发给别人的结果。**做完没人会把它发出去的工具，不进首批。**
2. **可分享产物必须自带站点标识**（卡片角落的 `plainkit.app`、复制链接默认带完整 URL），形成传播回流闭环。
3. **纯本地计算**，不向任何服务器发送数据。
4. **不用注册就能用**，打开即用。
5. **移动端可用**。

**为什么「可分享产物」是硬规则**：3 个月内拿不到搜索流量，唯一能自己掌握的增长机制就是让工具的结果本身值得被分享。

### 6.2 首批 5 个工具（按开发顺序）

| # | 工具 | 做什么 | 可分享产物 |
|---|---|---|---|
| 1 | **成绩与目标分数计算器** ✅ 已上线 | 输入各科目成绩和学分算加权平均；反向算「期末要考多少分才能把总评拉到目标」 | 「我期末要考 78 分才能保住 A」——学生真的会截图发给同学 |
| 2 | **倒计时 / 纪念日卡片** ✅ 已上线 | 输入一个日期，生成一张好看的倒计时卡片，可保存为图片、可复制链接 | **产出本身就是一张图**，为分享而生 |
| 4 | **日期时长计算器** ✅ 已上线 | 两个日期之间多少天、多少工作日、多少周；正着算倒着算都行 | 「我们认识 1000 天了」「距离毕业还有 217 天」——带情感的数字会被发出去 |
| 5 | **随机分组 / 抽签器** ✅ 已上线 | 粘贴名单，随机分成 N 组、随机抽几个人、抽奖、随机排序 | 分组结果天然要发给别人（老师发给班级、组织者发给群） |
| 6 | **图片 → ASCII 字符画**（2026-09-24 增补，取代化学工具的第 5 位开发顺位） | 上传本地图片，亮度映射成字符画，可调密度/字符集，复制文本或导出 PNG | **产物即内容**——ASCII 图天然要发 Discord / README / 群聊，全站唯一不需要额外造卡片的工具 |
| 7 | **二维码生成器**（2026-09-24 增补） | 把网址 / 文本 / Wi-Fi 信息编码成静态二维码，本地生成，PNG/SVG 导出 | **产物=二维码本身**，天然要印出去或发给别人；隐私牌：内容不出设备 |

> **注意序号**：编号是产品身份，不要重编。**开发顺序是 1 → 2 → 4 → 5 → 6 → 7**。
>
> **2026-09-24 决策变更**：化学工具（编号 3）**移出首批，转入第二期候选（复活制）**。原因：它是全站实现成本最高的工具（化学式解析 + 有理数线性方程组 + 氧化还原），但 3 个月验证窗口内没有可用分发渠道（新站无 SEO，r/InternetIsBeautiful 调性不符）。**复活条件**：用户自己的班级渠道仍在且愿意用它分发（班级渠道有学年保质期）；触发则提前到第 2–3 个月做。它仍是第二期 AI 增强（「解释这一步为什么」）的最佳位置。详细推理见 `specs/工具候选池.md`。

### 6.3 已降级与后续

- **第二个月**：百分比套件、文本清洗台（都是好工具，但**结果没人会截图分享**，用完就走，不产生传播）
- **后续三个月**：图片压缩 / PDF 处理（打「文件不离开你的电脑」的隐私牌）、单位换算类（等站点有权重再补，属长期资产）
- **化学工具（编号 3）**：移出首批，二期复活制（见 §6.2 决策变更）
- 后续候选池的完整调查（竞品格局 / 分享潜力 / 成本 / 裁决）见 `specs/工具候选池.md`

### 6.4 明确不做

| 不做 | 原因 |
|---|---|
| 贷款 / 房贷 / 税务计算 | 算错要赔钱；权威竞品有牌照和专业背书，扛不住 |
| BMI / 卡路里 / 医疗相关 | Google 有健康面板；健康建议有责任风险 |
| 单位换算、货币换算、温度换算、单一百分比 | Google 直接在搜索页给答案，做出来也是零流量 |
| AI 生成结果 | 核心功能全部确定性；AI 增强放第二期，且只允许在「结果可被验证」的场景加 |
