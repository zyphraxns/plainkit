> 定稿时间：2026-09-23

## 1. 背景与价值

**为什么做**：生日、考试、毕业、纪念日——普通人的重要日期散落在满屏广告的倒计时小站里，且几乎都要求注册或带水印。这是首批 5 个工具里唯一「产出本身就是一张图」的工具，为分享而生。

**做成什么样**：输入一个日期，立刻得到一张干净好看的倒计时/纪念日卡片——可下载为 PNG，可复制链接发给朋友打开实时观览页。

**竞品核实（2026-09-23，3 组关键词）**：Countz.io（分享链接依赖服务端）、101planners（思路最接近但界面重）、itwillbe / calculatoryourage / planningbirthday（SEO 农场质感）、howmanydaysuntil.christmas（窄垂直，证明「生成图片」成立）。**结论**：方向拥挤但「干净 + 无后端链接 + 图片即产物」的组合在普通人市场没有强者。

**关联**：`产品概述.md` §6.2 工具 2；开发顺序第 2 位（1 → 2 → 4 → 5 → 3）。

## 2. 范围

### 本次做

- 双向日期模式：未来日期 = 倒计时（N days to go）；过去日期 = 纪念日（N days ago）；今天 = "Today is the day!"
- 卡片自定义项：标题（可选）、日期（必填）、主题（3 选 1）、一句话附言（可选，≤80 字符）
- 3 套纯 CSS 绘制主题（无外部图片资源）
- PNG 下载：固定 1080×1080，2 倍清晰度导出，右下角 `plainkit.app` 站点标识
- 复制链接：全部状态编码在 URL 参数里，打开即全屏观览页（实时计算天数），顶部带「Make your own」按钮指向工具页
- 天数只显示「天」一个精度（不做时分秒）

### 本次不做

- 时/分/秒实时跳动 — 违反 DESIGN.md 动效红线；截图里的情感数字是「78 天」，不是「77 天 23:59:59」
- 竖版 / 横版多尺寸导出 — 首版复杂度明显上升，等用户反馈再定
- 上传图片背景、字体切换、emoji 选择器 — 与「视觉克制、零外部资源」冲突
- iframe 嵌入代码 — 面向开发者/站长的功能，不是本工具的目标用户
- 本地草稿自动保存 — 可作后续增强，首版不做
- 与工具 4（日期时长计算器）的边界：工具 4 是纯计算器（工作日、跨周），不产出图；本工具的产物是卡片本身

## 3. 用户与故事

**涉及角色**：普通用户（做卡片的人）、接收者（点开分享链接的人）

| 编号 | 用户故事 | 关联 AC |
|------|---------|---------|
| US-001 | 作为**普通用户**，我想要**输入一个日期立刻看到一张能截图的卡片**，以便**不用注册、不用挑模板挑半天就能分享** | AC-001, AC-002, AC-003, AC-004 |

## 4. 需求详述

### 4.1 核心流程

1. 用户打开工具页 → 填写标题（可选）、日期（必填）、主题（3 选 1）、附言（可选）
2. 卡片实时预览：按本地时区计算天数，未来 / 过去 / 今天三种状态自动切换
3. 用户选择 **Download PNG**（存图分享）或 **Copy link**（复制编码了全部状态的 URL）
4. 接收者打开链接 → 全屏观览页，实时显示倒计时，顶部「Make your own」按钮回到工具页

### 4.2 交互规则

- 表单与预览同屏：左侧表单、右侧卡片（桌面）；移动端上下排列
- 日期无效 / 为空时不渲染卡片数字，日期输入框标红提示
- 附言输入框实时显示字符计数，达 80 字符后禁止继续输入
- 标题留空时卡片不渲染标题行（不放假占位符）
- Copy link 点击后给出「已复制」反馈

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 纯本地计算：不向任何服务器发送数据；URL 参数是链接分享的唯一「存储」 |
| BR-002 | 无注册、无广告、无第三方脚本；界面为英文 |
| BR-003 | 可分享产物必须自带站点标识：PNG 与页面卡片右下角 `plainkit.app`；Copy link 产出完整域名 URL |
| BR-004 | 天数按用户本地时区的零点对齐计算（不引入 UTC 偏差） |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 未来日期倒计时
  - **Given** 已输入标题和一个未来日期
  - **When** 查看卡片
  - **Then** 显示「N days to go」（N = 目标日期零点与今天零点之差，本地时区），下方显示目标日期文本
- [ ] **AC-002**: 过去日期纪念日模式
  - **Given** 输入一个过去日期
  - **When** 查看卡片
  - **Then** 显示「N days ago」纪念日文案，布局与倒计时模式一致
- [ ] **AC-003**: 当天状态
  - **Given** 输入的日期就是今天
  - **When** 查看卡片
  - **Then** 显示 "Today is the day!"
- [ ] **AC-004**: 主题切换
  - **When** 在 3 个主题间切换
  - **Then** 卡片配色即时变化，无刷新、无闪烁
- [ ] **AC-005**: PNG 下载
  - **When** 点击 Download PNG
  - **Then** 得到 1080×1080 图片，内容与预览一致，含站点标识
- [ ] **AC-006**: 链接完整还原
  - **Given** 已填好标题、日期、主题、附言
  - **When** 点击 Copy link 并在新无痕窗口打开
  - **Then** 完整还原卡片全部状态，并按打开当天实时计算天数
- [ ] **AC-007**: 观览页
  - **Given** 通过分享链接打开
  - **Then** 看到无表单的全屏卡片观览页 + 「Make your own」按钮
- [ ] **AC-008**: 附言长度限制
  - **Given** 已输入 80 字符附言
  - **When** 尝试继续输入
  - **Then** 无法输入更多字符，且输入框显示字符计数

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-009**: 标题留空
  - **Given** 标题输入框为空
  - **Then** 卡片只渲染天数与日期，不出现空标题行
- [ ] **AC-010**: 日期为空或无效
  - **Given** 日期输入框为空或含无效值
  - **Then** 不渲染卡片数字，日期输入框标红提示
- [ ] **AC-011**: 超远日期
  - **Given** 目标日期距今超过 999 天
  - **Then** 4 位数字完整显示、不溢出卡片
- [ ] **AC-012**: 移动端布局
  - **Given** 视口宽度 390px
  - **Then** 工具页与观览页布局均不破
- [ ] **AC-013**: 长附言换行
  - **Given** 附言接近 80 字符
  - **Then** 自动换行且不遮挡天数数字
- [ ] **AC-014**: 时区零点对齐 ← BR-004
  - **Given** 同一目标日期
  - **When** 分别在今天 00:01 和 23:59 打开
  - **Then** N 值一致（本地时区零点对齐，无 UTC 偏差）
- [ ] **AC-015**: 链接参数被篡改
  - **Given** 分享链接的 URL 参数被改为非法值
  - **When** 打开观览页
  - **Then** 回退到安全默认状态，不崩溃

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-016**: 数据不出设备 ← BR-001
  - **Given** 任何用户操作
  - **Then** 不向任何服务器发送数据（网络面板无请求）
- [ ] **AC-017**: 四条底线与界面语言 ← BR-002
  - **Then** 无注册、无广告、无第三方脚本；界面为英文
- [ ] **AC-018**: 站点标识 ← BR-003
  - **Then** PNG 与页面卡片右下角带 `plainkit.app`；Copy link 产出完整域名 URL
