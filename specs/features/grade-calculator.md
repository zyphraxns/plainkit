> s8 需求澄清的产物。本文件是 s11 TDD 实现的**唯一验收依据**。
> slug 四处一致：`grade-calculator`（URL = `src/pages/tools/` 目录 = `src/lib/tools/` 目录 = 本文件名）。
>
> 定稿时间：2026-09-23

---

## 1. 背景与价值

**为什么做**：学生想知道「期末要考多少分才能把总评拉到目标」。现有答案散落在满屏广告的计算器网站里，且多数要求注册、加载慢、移动端不可用。

**做成什么样**：填三个数字（当前成绩、期末权重、目标总评），立刻看到「期末要考多少分」。结果值得截图发同学，或复制带参数的链接直接分享。

**关联**：首批工具 1（产品概述 §6.2，开发顺序第 1 位）。

---

## 2. 范围

### 本次做

- 单门课三输入模型：当前成绩（已修部分平均分）+ 期末权重 + 目标总评
- 反向计算：期末要考多少分才能达到目标总评，实时更新
- 不可达 / 已稳两种特殊状态的明确提示（告诉用户极限在哪，不只报错）
- Copy link（带 URL 参数的完整链接，打开即还原同样的输入与结果）
- 字段级错误提示（哪里错 + 怎么改）

### 本次不做

- 字母等级（A/B/C）—— 各校边界不同，算错会被质疑；第二期看反馈再定
- 多科目 GPA 加权平均 —— 是另一个工具，反向算期末在这个模型里不成立
- 组成项清单 / 详细模式 —— 首版以 30 秒用完为先
- 期末以外多场剩余考试 —— 只支持「除期末外已全部出分」这一场景
- 保存历史记录、暗色模式、多语言、AI —— 见产品概述与 DESIGN.md

## 4. 需求详述

### 4.1 核心流程

1. 用户打开 `/tools/grade-calculator/`，看到三个带 label 的输入框和结果区的邀请文案
2. 依次填入当前成绩、期末权重、目标总评，读数实时更新为「期末需要的分数」
3. 若目标数学上不可达或已稳，读数区改为对应的极限说明
4. 点 Copy link，把带参数的链接发给同学；对方打开即看到同样的输入与结果

### 4.2 交互规则

- 计算实时进行（输入变化即更新），无「计算」按钮
- 错误就地显示在字段下方；用户开始修正该字段时错误立即清除
- 一个字段同一时刻只显示一条错误，优先级：必填 > 格式 > 范围
- 结果读数带单位与上下文说明，不以裸数字出现
- 操作按钮只有 Copy link 一个（设计规范：最多两个，必含 Copy link）

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 三项输入均为 0–100 的数字；期末权重须为 1–100（0 会使计算无意义） |
| BR-002 | 所需期末分 =（目标 − 当前 ×（100 − 权重）/100）÷（权重/100）；内部不中途舍入，仅展示时保留 1 位小数 |
| BR-003 | 所需分 > 100 → 显示「不可达」与最高可达分；所需分 ≤ 0 → 显示「已稳」说明 |
| BR-004 | URL 参数与手输走完全相同的校验路径，不因参数来源跳过校验 |
| BR-005 | 全程零外部请求，计算全部在浏览器本地完成 |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 空状态邀请
  - **Given** 页面刚打开且无任何输入
  - **When** 查看页面
  - **Then** 三个字段带 label 可见，结果区显示「Enter your grades to see what you need on the final.」，无任何错误提示

- [ ] **AC-002**: 正向计算
  - **Given** 三个字段均为合法数字
  - **When** 输入当前 75、期末权重 40、目标 80
  - **Then** 读数显示 **87.5** 和说明「points on the final to reach 80%」

- [ ] **AC-003**: 实时更新
  - **Given** 已有一组有效输入和结果
  - **When** 修改任一字段的值
  - **Then** 读数即时更新，无需点击任何按钮

- [ ] **AC-004**: 复制分享链接
  - **Given** 已有一组有效输入和结果
  - **When** 点击 Copy link
  - **Then** 剪贴板内容是带当前输入参数的完整链接，并显示「Link copied」确认

- [ ] **AC-005**: 打开链接还原
  - **Given** 收到带合法参数的分享链接
  - **When** 打开页面
  - **Then** 三个字段预填为链接中的值，结果与发送者看到的一致

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-006**: 字段留空或非数字
  - **Given** 任一字段留空或填了非数字内容
  - **When** 查看结果区
  - **Then** 不显示计算结果（回到邀请文案），出错字段下方显示具体错误，如「Current grade must be a number.」

- [ ] **AC-007**: 数值超出范围
  - **Given** 任一字段填了 0–100 以外的数字（如当前成绩 120）
  - **When** 查看结果区
  - **Then** 该字段下方显示「Current grade must be between 0 and 100.」（字段名随实际字段变化），结果不更新

- [ ] **AC-008**: 期末权重为 0
  - **Given** 期末权重填 0
  - **When** 查看结果区
  - **Then** 显示「Final exam weight must be between 1 and 100.」，结果不更新

- [ ] **AC-009**: 目标不可达
  - **Given** 所需期末分数学上大于 100（例：当前 84、权重 30、目标 90）
  - **When** 查看结果区
  - **Then** 读数区显示「Not reachable. Even 100 on the final gives 88.8.」风格的极限说明（数字随输入计算）

- [ ] **AC-010**: 目标已稳
  - **Given** 所需期末分小于等于 0（例：当前 90、权重 10、目标 80）
  - **When** 查看结果区
  - **Then** 读数区显示「Already secured — even a 0 keeps you at 80 or above.」风格的说明

- [ ] **AC-011**: 链接参数非法
  - **Given** 收到参数被篡改的链接（如 `?currentGrade=abc`）
  - **When** 打开页面
  - **Then** 按无效输入处理（错误提示或回退空状态），不崩溃，校验路径与手输完全一致

- [ ] **AC-012**: 修正即清除
  - **Given** 某字段处于错误状态
  - **When** 用户开始修改该字段
  - **Then** 该字段的错误提示立即清除，不等重新校验完成

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-013**: 舍入规则 ← BR-002
  - **Given** 任何一组有效输入
  - **When** 计算与展示
  - **Then** 内部计算不中途舍入；展示值保留 1 位小数（例：87.46 显示为 87.5）

- [ ] **AC-014**: 零外部请求 ← BR-005
  - **Given** 页面在浏览器中运行
  - **When** 正常使用（输入、复制链接、加载）
  - **Then** 不发起任何对外部域名的请求，计算全部本地完成

- [ ] **AC-015**: 无 JS 可读
  - **Given** 浏览器禁用 JavaScript
  - **When** 打开页面
  - **Then** 表单、标签、说明文案完整可读，布局不塌（结果区显示邀请文案）

- [ ] **AC-016**: 读数规范 ← BR-002
  - **Given** 任何有效结果
  - **When** 展示
  - **Then** 结果数字带单位或上下文说明，不以裸数字出现；一页只有一个结果读数
