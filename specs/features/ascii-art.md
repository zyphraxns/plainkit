# 图片 → ASCII 字符画（ascii-art） — 功能需求说明书

> URL 路径 = `src/pages/tools/ascii-art/` = `src/lib/tools/ascii-art/` = `specs/features/ascii-art.md`。
>
> 定稿时间：2026-09-24

## 1. 背景与价值

**为什么做**：ASCII 字符画是把图片变成「能直接发出去的内容」的最短路径——发 Discord / README / 群聊，产物本身就是内容，是全站唯一不需要额外造卡片的工具。竞品核实（2026-09-24，3 组关键词）显示赛道**饱和**：imagetoascii.art（2026 新站，完成度极高，preset + TXT/PNG/SVG/ANSI 导出）、FreeMake.cc（4 种字符风格 + 本地处理）、toolshu.com/image2ascii、toolszone.net，且竞品已普遍做到「本地 + 免费 + 无水印」。

**裁决逻辑**：做它的理由不是差异化而是**传播效率 + 实现成本全站最低**（亮度采样 + 字符映射，纯函数一天量）+ r/InternetIsBeautiful 调性契合。竞品饱和在「统一入口」策略下可接受（分组工具同样饱和，已验证走得通）。

**做成什么样**：上传本地图片，按亮度映射成字符画；可调密度、字符集、反相、彩色；复制纯文本或导出 PNG（等宽渲染，解决手机聊天里等宽字体乱版的问题）。

**关联**：`产品概述.md` §6.2 工具 6（2026-09-24 增补，取代化学工具的第 5 位开发顺位）；开发顺序第 5 位（1 → 2 → 4 → 5 → 6 → 7）。

**证伪条件**：上线发帖两周内零分享 / 零回流 → 「产物即内容」假设失效（记录于 `工具候选池.md`）。

## 2. 范围

### 本次做

- 三合一图片输入：**文件选择 + 拖拽进页面 + 剪贴板粘贴（Ctrl/Cmd+V）**——覆盖「截图 → 粘贴 → 转 ASCII → 发 Discord」这条最高频路径
- 亮度映射生成 ASCII 字符画，输出宽度由密度参数（列数滑块）决定
- 四项调节参数**封顶**：密度（列数）、字符集三选（经典 `@#%*+=-:. ` 系 / 方块 `█▓▒░` 系 / 极简 `#*. ` 系）、反相（明暗翻转）、彩色开关（**默认单色**）
- 彩色模式：每个字符保留原图颜色，作用于**页面预览和 PNG 导出**；复制出的纯文本恒为单色（纯文本格式无颜色，这是格式决定的，不是功能缺陷）
- 一键复制纯文本（等宽、按预览行列原样）
- 导出 PNG：等宽字体渲染，角落带 `plainkit.app` 小字标识（§6.1 回流闭环），内容跟随当前彩色开关
- 空状态内置一张示例图，一键加载立即看到效果（零门槛理解工具用途）
- 参数调整即时刷新预览（本地计算量小，无需「生成」按钮）

### 本次不做

- **SVG 导出** — 等宽字符画没有真实的 SVG 使用场景，PNG 已覆盖分享需求；竞品有只是堆功能
- **亮度 / 对比度调节** — 多两个滑块对普通人是负担，多数人不会调；四项参数已覆盖风格变化的九成需求
- **URL 分享链接** — 图片既无法也不应编码进 URL（与随机分组工具的隐私决策一致）
- **多图批量处理** — 一次一张，场景成立
- **ANSI 转义序列导出** — 面向终端玩家的极小众形态，等真实需求
- **AI 增强**（「把这张图转成更好看的字符画风格」）— 二期，且须满足「结果可被验证」

## 4. 需求详述

### 4.1 核心流程

1. **进入页面** → 空状态显示上传提示 + 内置示例图入口，点击立即生成示例的 ASCII 效果
2. **导入图片** → 任一方式（选择 / 拖拽 / 粘贴）载入后自动生成 ASCII 预览，无需额外点击
3. **调节** → 密度、字符集、反相、彩色开关，四项均即时刷新
4. **导出** → 复制纯文本（恒单色），或导出 PNG（跟随彩色开关，带站点标识）

### 4.2 交互规则

- 未加载图片时，「复制」和「导出 PNG」按钮置灰（无空结果）
- 新图片载入或参数变化时预览即时刷新，不加「生成」按钮
- 载入失败（格式不支持 / 解码失败）时显示明确错误提示，且**不破坏已有结果**
- 彩色开关同时控制页面预览和 PNG 导出，两处永远一致

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 全程本地处理：图片解码、采样、渲染、导出均在浏览器完成，不发出任何携带图片数据的网络请求 |
| BR-002 | 可分享产物带站点标识：PNG 角落带 `plainkit.app`；复制文本**不**加任何尾巴（污染内容会被弃用，文本形态的回流由 PNG 承载） |
| BR-003 | 输出宽度只由密度参数决定，与原图像素无关（超大图内部自动降采样） |
| BR-004 | 输出宽高比与原图视觉一致（按字符实际高宽比校正，不拉扁） |
| BR-005 | 无注册、无广告、无追踪、零第三方脚本（全站四底线） |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 空状态示例图
  - **Given** 用户打开工具页且未导入图片
  - **When** 用户点击内置示例图
  - **Then** 立即生成该图的 ASCII 结果，四项调节参数全部可用

- [ ] **AC-002**: 三合一导入
  - **Given** 用户在工具页
  - **When** 用户通过文件选择、拖拽进页面、或 Ctrl/Cmd+V 粘贴任一方式导入图片
  - **Then** 图片载入后自动生成 ASCII 预览，无需额外点击

- [ ] **AC-003**: 密度调节
  - **Given** 已生成 ASCII 结果
  - **When** 用户调整密度（列数）
  - **Then** 预览即时刷新，列数越多细节越丰富，行数随原图宽高比相应变化

- [ ] **AC-004**: 字符集切换
  - **Given** 已生成 ASCII 结果
  - **When** 用户切换字符集（经典 / 方块 / 极简）
  - **Then** 预览即时刷新，三种风格肉眼可辨明显不同

- [ ] **AC-005**: 反相
  - **Given** 已生成 ASCII 结果
  - **When** 用户开启反相
  - **Then** 明暗映射翻转：原图亮区用暗字符、暗区用亮字符；关闭则恢复

- [ ] **AC-006**: 彩色开关
  - **Given** 已生成单色 ASCII 结果
  - **When** 用户开启彩色开关
  - **Then** 页面预览和 PNG 导出变为彩色（每字符保留原图色）；关闭则两处同时回到单色；默认状态为单色

- [ ] **AC-007**: 复制文本
  - **Given** 已生成 ASCII 结果
  - **When** 用户点击复制文本
  - **Then** 剪贴板得到与预览行列一致的等宽纯文本，无多余首尾空行，无站点尾巴（BR-002）

- [ ] **AC-008**: 导出 PNG
  - **Given** 已生成 ASCII 结果
  - **When** 用户点击导出 PNG
  - **Then** 得到等宽字体渲染的图片，文字清晰不烂版，角落带 `plainkit.app` 小字标识（BR-002），色彩跟随当前彩色开关状态

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-009**: 非图片文件
  - **Given** 用户准备导入图片
  - **When** 用户拖拽或选择非图片文件（如 .txt / .pdf）
  - **Then** 显示明确的错误提示，页面上已有的结果不被破坏

- [ ] **AC-010**: 浏览器无法解码的格式
  - **Given** 用户导入的图片格式当前浏览器无法解码（如 Chrome 下的 HEIC）
  - **When** 载入失败
  - **Then** 显示「此格式无法在浏览器解码，请使用 JPG / PNG / WebP」类提示（英文界面），已有结果不被破坏

- [ ] **AC-011**: 透明背景
  - **Given** 用户导入含透明区域的 PNG
  - **When** 生成
  - **Then** 透明区域按白色底合成，单色与彩色模式行为一致

- [ ] **AC-012**: GIF 动图
  - **Given** 用户导入 GIF 动图
  - **When** 生成
  - **Then** 取第一帧生成静态 ASCII，不报错不闪烁

- [ ] **AC-013**: EXIF 方向
  - **Given** 用户导入手机竖拍照片（带 EXIF 方向信息）
  - **When** 生成
  - **Then** 输出方向与照片实际方向一致（不横躺）

- [ ] **AC-014**: 超大图片
  - **Given** 用户导入像素尺寸极大的图片
  - **When** 生成
  - **Then** 正常出结果不卡死（内部自动降采样），输出由密度参数决定（BR-003），页面不崩溃

- [ ] **AC-015**: 未选图片时的导出
  - **Given** 页面处于未加载图片状态
  - **When** 用户查看复制 / 导出按钮
  - **Then** 按钮置灰不可点，不产生空结果

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-016**: 纯本地处理 ← BR-001
  - **Given** 用户进行包括导入、生成、复制、导出在内的任何操作
  - **When** 观察网络请求
  - **Then** 不发出任何携带图片数据的网络请求，图片数据不出设备

- [ ] **AC-017**: 宽高比校正 ← BR-004
  - **Given** 用户导入一张正方形图片
  - **When** 生成
  - **Then** 输出结果视觉上接近正方形，不被字符高宽比拉成瘦长形

- [ ] **AC-018**: 移动端可用
  - **Given** 用户在手机浏览器打开工具页
  - **When** 完成导入、调节、复制、导出全流程
  - **Then** 触屏可选择图片、预览可清晰查看、按钮均可点、布局不溢出

- [ ] **AC-019**: 全站四底线 ← BR-005
  - **Given** 用户使用本工具的任何功能
  - **When** 观察
  - **Then** 无注册要求、无广告、无追踪、无第三方脚本
