# 随机分组 / 抽签器（random-picker） — 功能需求说明书

> 工具 5（产品编号）。slug `random-picker`，四处命名必须一致：
> URL 路径 = `src/pages/tools/random-picker/` = `src/lib/tools/random-picker/` = `specs/features/random-picker.md`。
>
> 定稿时间：2026-09-24

## 1. 背景与价值

**为什么做**：老师分小组、活动组织者抽人、游戏玩家随机分队——这些需求散落在满屏广告的分组小站里。竞品核实（2026-09-24，3 组关键词：random group generator / team picker wheel / classroom random student picker no signup）显示方向**高度拥挤**：randomgroup.org、miniwebtool（2010 年至今、月 200 万次运行）、Inqita、onlinetoolsforge、NameWheel、PickerSpin 等，且多数已支持「无注册 + 纯本地计算」——**单靠干净已不足以差异化**。

**共同短板即我们的空档**：竞品的结果全部是纯文本 / TXT / CSV，没有「值得截图」的产物。本工具按 Brief 的「可分享产物」策略做一张带 PlainKit 标识的结果卡片——分组结果天然要发班级群 / 玩家群，图片比文本更有传播性。

**做成什么样**：粘贴名单，一键随机分组（按组数或按每组人数）、不放回抽人、随机排序；结果可保存为带站点标识的图片卡片，可一键复制纯文本。

**关联**：`产品概述.md` §6.2 工具 5；开发顺序第 4 位（1 → 2 → 4 → 5 → 3）。

## 2. 范围

### 本次做

- 三种模式合一页：
  - **分组**：按组数（N groups）或按每组人数（N per group）两种切法，均衡分配（组间人数差 ≤ 1，余数从第 1 组往后逐组分）
  - **抽人**：不放回随机抽 N 个互不相同的人
  - **随机排序**：整份名单打乱顺序
- 输入解析：每行一个名字，兼容逗号 / 分号分隔；自动忽略空行与首尾空白
- 结果图片卡片：PNG 下载，含分组结果、日期、右下角 `plainkit.app` 站点标识（§6.1 回流闭环）
- 一键复制纯文本（组名 + 成员，直接可粘贴进聊天软件）
- 名单自动保存在浏览器本机（localStorage），提供「清除名单」按钮
- 重复名字检测提示 + 一键去重（不自动删除）

### 本次不做

- **抽卡模拟（游戏模式）** — 接游戏社区分发的钩子，但交互设计（稀有度、概率展示）值得单独一轮需求澄清，下个迭代做
- **URL 分享链接** — 名单是人名，编码进 URL 会永久留在聊天记录和浏览器历史里，隐私风险不值得
- **多名单管理**（保存多份班级名单并切换）— 首版只保留最近一次名单，等用户反馈再定
- **文件导入**（TXT / CSV / Excel）— 粘贴已覆盖 90% 场景
- **平衡分组**（按性别、能力均衡）— 属高级功能，且需要额外属性输入，与「打开即用」冲突
- **转盘 / 抽奖动画** — 违反 DESIGN.md 动效红线（动效只允许结果出现时的轻微过渡），且 Wheel of Names 系已把转盘做到头，不做同质化竞争
- 与工具 2（倒计时卡片）的边界：工具 2 的产物是日期卡片；本工具的产物是名单结果卡片，两者不重叠

## 4. 需求详述

### 4.1 核心流程

1. 用户打开工具页 → 名单框（若之前用过，上次名单已在）→ 粘贴名单
2. 选模式与参数（分组：组数或每组人数；抽人：抽几个人；排序：无参数）
3. 点生成 → 结果即时显示，出现轻微过渡动效（DESIGN.md 允许的唯一动效）
4. 保存图片卡片 / 复制纯文本 / 点「重新生成」换一批结果

### 4.2 交互规则

- 模式切换保留已输入的名单，不清空
- 生成按钮在名单不足时置灰，并显示引导文案（告知缺什么）
- 重复名字提示出现在生成结果旁，去重按钮一键移除重复项并保留首次出现的名字
- 「重新生成」使用当前设置重新随机；旧结果区域整体替换，不残留
- 复制成功有可见确认（如按钮短暂变为 "Copied"），不用弹窗
- 清除名单需点击确认（防误触），清空后立即生效

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 全部计算在浏览器本地完成，任何操作不发出网络请求 |
| BR-002 | 名单仅保存在本机浏览器（localStorage），提供一键清除 |
| BR-003 | 随机必须均匀无偏，反复运行不产生固定模式 |
| BR-004 | 无广告、无追踪、无第三方脚本、无注册 |
| BR-005 | 分组结果必须均衡：任意两组人数差 ≤ 1；余数从第 1 组往后依次多分 1 人 |
| BR-006 | 每个名字在单次结果中恰好出现一次（分组与排序）；抽人模式抽出的名字互不重复 |
| BR-007 | 名单容量上限 300 人，超出提示 |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 按组数分组
  - **Given** 名单 23 人
  - **When** 选「按组数 = 4」并生成
  - **Then** 显示 4 组，每组 5–6 人，所有名字恰好出现一次
- [ ] **AC-002**: 按每组人数分组
  - **Given** 名单 23 人
  - **When** 选「每组 3 人」并生成
  - **Then** 生成 8 组，前 7 组每组 3 人、最后一组 2 人
- [ ] **AC-003**: 不放回抽人
  - **Given** 名单 30 人
  - **When** 在抽人模式输入抽 5 人并生成
  - **Then** 显示 5 个互不相同且来自名单的名字
- [ ] **AC-004**: 随机排序
  - **Given** 名单 10 人
  - **When** 点随机排序
  - **Then** 输出包含全部 10 人且顺序被打乱
- [ ] **AC-005**: 保存图片卡片
  - **Given** 已有分组结果
  - **When** 点「保存图片」
  - **Then** 下载一张 PNG 卡片，含分组结果、日期、右下角 `plainkit.app` 标识，在手机上查看清晰不糊
- [ ] **AC-006**: 复制纯文本
  - **Given** 已有分组结果
  - **When** 点「复制文本」
  - **Then** 剪贴板得到格式化纯文本（组名 + 成员各占一行），可直接粘贴进聊天软件，按钮显示复制成功状态
- [ ] **AC-007**: 重新生成
  - **Given** 已有结果
  - **When** 点「重新生成」
  - **Then** 在相同设置下产生新的随机结果，旧结果不残留

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-008**: 输入容错
  - **Given** 输入含空行、行首尾空格、逗号或分号分隔
  - **When** 生成
  - **Then** 名字被正确切分，空白项被忽略，人数统计准确
- [ ] **AC-009**: 重复名字
  - **Given** 名单含重复名字
  - **When** 生成
  - **Then** 显示重复提示，提供一键去重（保留首次出现），不自动删除
- [ ] **AC-010**: 名单不足
  - **Given** 名单为空或仅 1 人
  - **When** 查看生成按钮
  - **Then** 按钮不可用，显示引导文案（如「至少需要 2 个名字」）
- [ ] **AC-011**: 组数超过人数
  - **Given** 名单 5 人，输入组数 8
  - **When** 生成
  - **Then** 组数被限制为 5，显示提示
- [ ] **AC-012**: 抽人数量超限
  - **Given** 名单 10 人，输入抽 15 人
  - **When** 生成
  - **Then** 输入被限制为 10，显示「最多可抽 10 人」提示
- [ ] **AC-013**: 大名单
  - **Given** 名单约 300 人
  - **When** 生成并保存图片
  - **Then** 页面不卡顿，卡片完整包含所有结果
- [ ] **AC-014**: 名单超上限
  - **Given** 输入超过 300 人
  - **When** 粘贴
  - **Then** 显示超限提示并只保留前 300 人

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-015**: 本地计算 ← BR-001, BR-004
  - **Given** 打开工具页
  - **When** 进行任意操作
  - **Then** 无任何网络请求，页面无广告、无追踪脚本
- [ ] **AC-016**: 名单本地保存 ← BR-002
  - **Given** 输入名单后刷新或关闭页面再打开
  - **When** 查看名单框
  - **Then** 上次名单自动恢复；点「清除名单」确认后立即清空
- [ ] **AC-017**: 随机均匀性 ← BR-003, BR-006
  - **Given** 同一名单反复分组多次
  - **When** 观察结果分布
  - **Then** 每个人出现在各组的频率无固定模式；单次结果中每个名字恰好出现一次
- [ ] **AC-018**: 移动端可用 ← BR-004
  - **Given** 手机浏览器打开工具页
  - **When** 完成输入到分享全流程
  - **Then** 布局无横向溢出，按钮可正常触达
