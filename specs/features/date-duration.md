## 1. 背景与价值

**为什么做**：「我们认识 1000 天了」「距离毕业还有 217 天」这类**带情感的数字**天然会被发给别人，符合 PlainKit「可分享产物」选品标准。竞品核实（3 组关键词，2026-09-23）：日期差值类工具饱和且臃肿（CalcDen、precisecalculators 等塞 6–8 个结果块）；纪念日里程碑类 waza.tools 验证了「100/1000/10000 天」钩子的需求，但无分享闭环；工作日历类需维护节假日数据，违背轻量原则。**空档 = 干净 + 情感数字 + 可分享链接**。

**做成什么样**：输入两个日期（终点默认今天），立即得到总天数、周/年月日/工作日分解和未来里程碑（100/1000/10000 天档位），结果可通过链接分享给任何人。

**关联**：`PROJECT-BRIEF.md` 工具 4 · `specs/产品概述.md` §6.2 · 开发顺序 1 → 2 → **4** → 5 → 3

## 2. 范围

### 本次做

- 统一双输入模型：起点 + 终点，**终点默认今天**（算纪念日 = 过去起点 + 今天；算倒计时 = 今天 + 未来终点）
- 大数字总天数 + 次级分解（周+剩余天、年月日、工作日数、周末日数）
- 里程碑区：7 个固定天档位（100 / 365 / 500 / 1000 / 2000 / 5000 / 10000），起点在过去时显示，高亮下一个未到的
- 可选标签（≤60 字符，沿用 countdown-card 上限），进入标题与复制文案
- 分享链接：URL 参数编码 + 观览模式（复用 countdown-card 机制）
- 复制文本：含结果与 PlainKit 的英文句子

### 本次不做

- 节假日历（按国家扣减法定节假日）— 重数据维护、违背轻量原则，业界惯例也是注明「不含节假日」
- 日期加减模式（add/subtract duration）— 竞品已有，且与「情感数字」定位无关
- 小时 / 分钟 / 秒级实时跳动 — 花哨无传播价值（randomly.online 已验证没人需要）
- PNG 卡片 — 本工具产物是数字不是画面；第二期有需求再走 s12 变更
- live tick（跨零点自动刷新）— 页面按打开时的「今天」计算，刷新即更新
- 多语言 — 英文界面是全站第一版约定

## 4. 需求详述

### 4.1 核心流程

1. 打开工具页：终点预填今天、起点为空，不显示结果区
2. 填入起点（终点保持今天）→ 立即显示总天数与次级分解；起点在过去时出现里程碑区
3. 可选：改终点为未来日期算倒计时、填标签个性化文案、点 Copy 复制文本、复制 URL 分享
4. 对方打开链接 → 观览模式（无表单）看到同样结果，点 Make your own 返回表单

### 4.2 交互规则

- 所有结果**输入即算**（无提交按钮）
- 终点早于起点时**自动交换**并显示提示，不做负数
- 措辞跟随日期关系：终点=今天或过去 →「N days since 日期」；终点在未来 →「N days until 日期」
- 里程碑区仅当起点在过去时渲染；下一个未到的档位高亮并显示「in N days」
- URL 同步用 replaceState（不产生浏览历史）
- 工作日数字附近有脚注：「Weekdays are Monday–Friday. Public holidays are not excluded.」

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 天数口径全局一致为 end − start（不含头，不加 1）；工作日在 [start, end) 区间内统计 |
| BR-002 | 工作日 = 周一至周五，不扣法定节假日 |
| BR-003 | 所有计算纯本地完成，不向任何服务器发送数据 |
| BR-004 | 标签 ≤ 60 字符（与 countdown-card 一致），超长截断 |
| BR-005 | 日期运算用本地时区零点对齐 + round 吸收 DST（沿用 countdown-card 结论） |
| BR-006 | 工具页 JS gzip ≤ 10KB（DESIGN.md 性能红线），复用既有工具台模板与 URL 编码机制 |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 空态
  - **Given** 打开工具页且 URL 无参数
  - **When** 页面加载完成
  - **Then** 终点日期预填今天、起点为空、结果区不显示

- [ ] **AC-002**: 纪念日主场景
  - **Given** 终点为今天
  - **When** 填入一个过去的起点日期
  - **Then** 立即显示大数字总天数（end − start，不加 1），措辞为「N days since 日期」

- [ ] **AC-003**: 倒计时场景
  - **When** 把终点改为未来日期
  - **Then** 措辞切换为「N days until 日期」；改回今天或过去则恢复「N days since」

- [ ] **AC-004**: 次级分解
  - **Given** 两个有效日期
  - **Then** 同时显示：周+剩余天、年月日分解、工作日数、周末日数，且工作日 + 周末日 = 总天数

- [ ] **AC-005**: 里程碑区
  - **Given** 起点在过去
  - **Then** 显示 7 个档位（100/365/500/1000/2000/5000/10000 天），各含日期+星期+已过/未到状态；下一个未到的被高亮并显示「in N days」

- [ ] **AC-006**: URL 同步
  - **When** 修改起点 / 终点 / 标签
  - **Then** URL 参数实时同步（replaceState，不产生历史记录）

- [ ] **AC-007**: 观览模式
  - **Given** 打开带有效参数的分享链接
  - **When** 页面加载完成
  - **Then** 表单隐藏、结果完整显示，并有 Make your own 链接返回表单模式

- [ ] **AC-008**: 复制文本
  - **When** 点击 Copy
  - **Then** 剪贴板得到含结果与 PlainKit 的英文句子；有标签时句子包含标签

- [ ] **AC-009**: 无标签中性文案
  - **Given** 标签留空
  - **Then** 标题与复制文案使用中性措辞（仅日期与数字）

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-010**: 起点等于终点
  - **Given** 起点 = 终点
  - **When** 计算触发
  - **Then** 显示 0 天，各分解为 0，无报错

- [ ] **AC-011**: 终点早于起点
  - **Given** 填入的终点早于起点
  - **When** 计算触发
  - **Then** 自动交换两个日期并显示已交换提示，结果按交换后计算

- [ ] **AC-012**: 起点为空
  - **Given** 起点为空（或无效）
  - **Then** 不显示结果区

- [ ] **AC-013**: 跨夏令时
  - **Given** 起止日期跨越本地时区的 DST 切换（如 2026-03-08 前后）
  - **Then** 天数不多不少，无 ±1

- [ ] **AC-014**: 闰年
  - **Given** 2024-02-28 → 2024-03-01
  - **Then** 结果为 2 天；Given 起点 2024-02-29，Then 起点+365 天 = 2025-02-28

- [ ] **AC-015**: 非法分享链接
  - **Given** URL 参数缺失或非法（任一步解析失败）
  - **When** 页面加载
  - **Then** 安全回退到空表单模式，不报错

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-016**: 纯本地计算 ← BR-003
  - **Given** 任何操作
  - **Then** 页面发出外部请求为 0（网络面板可见）

- [ ] **AC-017**: 工作日口径 ← BR-001, BR-002
  - **Given** 2026-09-21（周一）→ 2026-09-26（周六）
  - **Then** 总天数 5、工作日 5、周末日 0（[start, end) 不含周六）；UI 脚注注明不扣法定节假日

- [ ] **AC-018**: 标签截断 ← BR-004
  - **Given** 输入超过 60 字符的标签
  - **Then** 被截断到 60 字符，标题与文案使用截断后的标签

- [ ] **AC-019**: 性能红线 ← BR-006
  - **Given** 构建产物
  - **Then** 工具页 JS gzip ≤ 10KB
