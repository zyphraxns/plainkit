# PlainKit · 错题本

> 用途见 `specs/DESIGN.md` §14.5。当 AI 生成的代码出问题时在此追加记录。
>
> **核心机制**：当同类错误出现**第二次**时，说明该在 `DESIGN.md` 里加一条硬规则，而不是继续靠 Agent 记住。**第二次出现同类错误时，必须同时修订 `DESIGN.md`。**

---

## 记录格式

```markdown
## YYYY-MM-DD · <一句话标题>

| 项 | 内容 |
|---|---|
| **类型** | 类型错误 / 逻辑错误 / 规范违规 / 依赖错误 / 性能超预算 |
| **现象** | 具体出了什么问题 |
| **根因** | 为什么会犯（如果是规范没写清，必须写明 DESIGN.md 哪一节需要补充） |
| **正确做法** | 下次怎么做 |
| **规范修订** | DESIGN.md 已补充 §x.y / 无需修订 |
```
