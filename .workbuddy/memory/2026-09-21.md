### 关键硬规则（写进文档的）

- `src/lib/` 下禁止 `document`/`window`/`navigator`/`localStorage`（红线 1）
- 页面初始化不得发起任何对外请求，全站外部请求数 0（红线 2）
- 没有失败的测试就不写实现代码（红线 3）
- **输入框字号必须 ≥16px**（iOS Safari 聚焦时自动放大会让页面「跳一下」，小工具站最常翻的车）
- **禁止 `innerHTML`**（用户会粘贴任意文本，这是本项目最现实的攻击面）
- **禁止 `style="..."` 内联属性**（CSP 会拦），改用 CSSOM `el.style.setProperty()`（不受 CSP 限制）
- **禁止嵌套量词正则**（ReDoS 会让主线程卡死）
- **CSP 里 `connect-src 'none'`**——让浏览器本身拒绝页面发起任何网络连接。「数据不出设备」从承诺变成用户可自行验证的技术事实。**这是本项目最有说服力的技术差异**
- **测试名必须以 `AC-xxx:` 开头**——用户不读代码，`grep AC-004` 是他能抓住的唯一证据链
- 依赖方向：pages → components → lib 单向；`lib/tools/A` 不得 import `lib/tools/B`
- TS 禁止：`any` / 非空断言 `!` / `as` 断言 / `enum` / `@ts-ignore`（用 `@ts-expect-error` + 理由）
- 逻辑层不抛异常，返回判别式联合 `Result<T>`
- 不引 ESLint（TS strictest + Prettier 已够）；**触发条件**：出现一次类型检查抓不到的规范违规就加

### 踩到并修掉的 6 个真坑（全部写进 DESIGN.md 与初始化记录）

1. **TypeScript 必须锁 6.x**：TS 7 的原生编译器不暴露 `astro check` 依赖的 programmatic API → `npm run typecheck` 直接报错退出。`@astrojs/check@0.9.10` 的 peer 要求是 `^5||^6`。**不要为了用新版放弃 `astro check`**——.astro 文件的类型检查只有它能做
2. **`astro.config` 必须设 `inlineStylesheets: 'never'`**：默认会把 <4KB 样式表内联成 `<style>`，而 CSP 是 `style-src 'self'`（无 unsafe-inline）→ **线上页面完全没样式，而本地开发完全看不出问题**
3. **tsconfig 不能用 `baseUrl`**：TS 6/7 已废弃，报 TS5101。去掉后 paths 按 tsconfig 所在目录解析
4. **`vitest.config.ts` 需要 `/// <reference types="vitest/config" />`**：否则 `getViteConfig` 返回类型不认 `test` 字段，报 TS2353
5. **性能门禁的外部域名扫描只扫「会发起请求的位置」**（HTML 的 src/srcset/action/link[href]、CSS 的 url()/@import、JS 全部 URL），**不扫散文**：About 页说明文字里写着 `http://localhost:8080`，全文扫描会误判。**天天误报的门禁最终会被关掉，比没有更糟**
6. **`frame-ancestors` 只能走 HTTP 头**：写在 `<meta>` 里会被浏览器忽略 → 完整安全头放 `public/_headers`（Cloudflare 生效），GH Pages 靠 meta CSP 兜底

### 环境坑（本机实测，值得记住）

- **zsh 不对未加引号的变量做词分割**（bash 会）：`F="--a --b"; cmd $F` 会把整串当成**一个**参数传给 cmd，静默失效。要写 `${=F}` 或内联参数
- **Bash 工具里 PATH 会不定时丢失**（`grep`/`ls`/`tail` 报 command not found）→ 每条命令显式 `export PATH=...`，复杂操作写成 `.sh` 用 `/bin/bash` 跑
- **Chrome headless 窄窗口不可信**：`--window-size=390` 时布局宽度仍 >390（窗口最小宽度限制），截图是裁剪而非真实 390 布局。**验证窄屏要用 iframe 强制视口宽度**
- `--headless=new` 需 `--in-process-gpu --no-sandbox --disable-gpu --disable-dev-shm-usage`；`--headless=old` 同样可用
- `astro preview` 在本沙箱不稳定（会挂，curl 返回 502）→ 用 `python3 -m http.server --directory dist` 替代
